# inAmigo — Website

A small static website for the inAmigo project (premium page included).

**Author:** Avi Sharma

## Description

This repository contains a simple static site and a small helper script. The site includes a main entry page and a premium page.

## Project structure

- [inamigos_premium (1).html](./inamigos_premium%20%281%29.html)
- [index.html](./index.html)
- [assets/check_images.py](./assets/check_images.py)
- [gallery](./gallery)

## Requirements

- A modern web browser to view the HTML files.
- Python 3.x to run `assets/check_images.py` (optional).

## Usage

Open the site pages in your browser. Example:

- Open [index.html](./index.html) in your browser.
- To view the premium page open [inamigos_premium (1).html](./inamigos_premium%20%281%29.html).

If you want to run the image-check helper script:

```bash
python assets/check_images.py
```

## Notes

- No build system is required — files are static.
- If you add dependencies for `assets/check_images.py`, add a `requirements.txt`.
